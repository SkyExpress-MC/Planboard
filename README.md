# Planboard

## Workflows

- **Test Skript Syntax** 
Runs on every push and pull request.
Spins up a Paper server (Minecraft 1.21, Skript 2.12.1, Java 21) and validates the scripts in `./Skript` along with the addons in `./addons`.

<br>

## Issue Templates

- **Goal** (`📍`) 
For high-level goals that bundle multiple tasks. 
Asks for a description and an importance level (High / Mid / Low).


- **Task** (`📋`)
For sub-issues that belong to a goal. 
Asks for any relevant info and a task type (Discover / Create / Rework).
